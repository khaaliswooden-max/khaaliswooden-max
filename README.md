#### Working on

- **[RuralSim](https://github.com/khaaliswooden-max/ruralsim)** · [ruralsim.io](https://ruralsim.io)
  A free, open-source (Apache-2.0) 3D world model of rural U.S. counties. Five pilot counties are built as OpenUSD worlds, and a national table covers all 3,144 counties. It tests AI-era infrastructure, energy, and services before anyone spends real money, and it scores each intervention on a Rural Quality of Life Index with hard equity constraints.
- **[Get Rural America Done](https://github.com/khaaliswooden-max/grad56)** · [getruralamericadone.com](https://getruralamericadone.com)
  A rural health and Critical Access Hospital modernization practice covering all 56 U.S. states and territories. It runs *Grid & Grain*, a free public-education series. *You decide it together. We help get it done.*
